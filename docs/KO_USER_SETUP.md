# Local Prompt Studio 한국어 설치 가이드

이 문서는 컴퓨터나 GitHub에 익숙하지 않은 사용자를 위한 안내입니다.

Local Prompt Studio는 이미지를 넣으면 로컬 AI 모델을 이용해 이미지 생성용 프롬프트를 만들어주는 Windows 앱입니다.

## 1. 어디에서 다운로드하나요?

GitHub 저장소로 이동합니다.

```text
https://github.com/openerai/local-prompt-studio
```

오른쪽 또는 상단 근처에서 `Releases`를 찾습니다.

`Releases` 안에서 가장 최신 버전을 클릭합니다.

그 아래의 `Assets` 영역에서 Windows 설치 파일을 다운로드합니다.

보통 이름은 이런 형태입니다.

```text
Local Prompt Studio Setup 1.0.0.exe
```

또는 비슷한 `.exe` 설치 파일을 받으면 됩니다.

## 2. Code 버튼으로 받으면 안 되나요?

GitHub의 초록색 `Code` 버튼은 개발자용 소스코드를 받는 버튼입니다.

일반 사용자는 `Code` 버튼이 아니라 `Releases`에서 설치 파일을 받는 것이 가장 쉽습니다.

## 3. Local Prompt Studio 설치

다운로드한 `.exe` 파일을 실행합니다.

Windows에서 경고가 뜰 수 있습니다. 직접 만든 앱이라 처음에는 이런 경고가 나올 수 있습니다.

설치를 완료한 뒤 Local Prompt Studio를 실행합니다.

## 4. LM Studio 설치

Local Prompt Studio는 AI 모델을 직접 실행하지 않고, LM Studio에 연결해서 사용합니다.

LM Studio가 없다면 아래 사이트에서 설치합니다.

```text
https://lmstudio.ai/
```

설치 후 LM Studio를 실행합니다.

## 5. 모델 다운로드

LM Studio에서 이미지 인식이 가능한 모델을 다운로드해야 합니다.

모델 검색 시 이런 단어가 들어간 모델을 찾으면 좋습니다.

```text
vision
vl
llava
qwen-vl
multimodal
image
```

텍스트 전용 모델은 이미지를 제대로 분석하지 못할 수 있습니다.

## 6. 모델 Load 하기

모델을 다운로드만 하면 끝이 아닙니다.

LM Studio에서 해당 모델을 `Load` 해야 Local Prompt Studio가 사용할 수 있습니다.

모델이 로드되어 있어야 Local Prompt Studio의 모델 목록에 나타납니다.

## 7. Local Prompt Studio에서 연결하기

Local Prompt Studio를 엽니다.

오른쪽 설정 영역에서 다음 순서로 진행합니다.

1. `환경 체크`를 누릅니다.
2. 문제가 있으면 `자동 준비`를 누릅니다.
3. `Refresh`를 누릅니다.
4. LM Studio에서 로드한 모델을 선택합니다.

## 8. 이미지로 프롬프트 만들기

1. 이미지를 작업공간으로 드래그합니다.
2. 결과 스타일을 선택합니다.
   - `태그형`
   - `문장형`
   - `시스템 프롬프트형`
3. 디테일 정도를 선택합니다.
4. `프롬프트 생성`을 누릅니다.

같은 이미지에서 여러 번 생성하면 결과 히스토리에 저장됩니다.

## 9. 프로젝트는 어디에 저장되나요?

프로젝트는 자동으로 아래 위치에 저장됩니다.

```text
C:\Users\<사용자이름>\AppData\Roaming\local-prompt-studio\projects
```

앱 왼쪽의 `폴더 열기` 버튼을 누르면 저장 위치를 바로 열 수 있습니다.

## 10. 이미지 용량이 걱정될 때

기본 설정에서는 원본 이미지 경로만 저장합니다.

즉, 프로젝트 파일이 너무 커지지 않습니다.

다만 원본 이미지를 삭제하거나 이동하면 앱에서 이미지를 다시 불러오지 못할 수 있습니다.

이미지까지 프로젝트에 같이 저장하고 싶으면 `이미지를 프로젝트에 복사 저장`을 켜면 됩니다.

## 11. 업데이트는 어떻게 하나요?

앱에는 업데이트 확인 기능이 있습니다.

왼쪽 메뉴의 `업데이트 확인` 버튼을 누르면 새 버전이 있는지 확인합니다.

새 버전이 있으면 다운로드 후 앱을 다시 시작해 설치할 수 있습니다.

업데이트가 잘 안 되면 GitHub의 `Releases`에서 최신 설치 파일을 다시 다운로드해 설치하면 됩니다.

## 12. 자주 생기는 문제

### 모델 목록이 비어 있어요

LM Studio에서 모델을 `Load` 했는지 확인하세요.

그 다음 Local Prompt Studio에서 `Refresh`를 누르세요.

### 프롬프트 생성이 안 돼요

다음을 확인하세요.

1. LM Studio가 실행 중인지
2. 모델이 Load 되어 있는지
3. Vision 모델인지
4. Local Prompt Studio에서 모델을 선택했는지
5. 이미지를 넣었는지

### 결과가 너무 짧아요

`디테일`을 `상세`로 바꿔보세요.

또는 `추가 지시`에 원하는 방향을 적어보세요.

예:

```text
의상과 배경을 자세히, 카메라 구도와 조명을 길게 설명
```
