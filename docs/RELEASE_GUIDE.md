# Release Guide

Use this guide when publishing a new version of Local Prompt Studio.

## 1. Update Version

Edit `package.json`:

```json
"version": "1.0.1"
```

Use a simple version pattern:

```text
1.0.0
1.0.1
1.1.0
2.0.0
```

## 2. Test

Run:

```bash
npm install
npm run test:syntax
npm start
```

Check:

- App opens
- Environment check works
- Model refresh works
- Model test works
- Image drag/drop works
- Prompt generation works
- WebP images are converted before generation
- Project save/load works
- Prompt history works

## 3. Build Installer

Run:

```bash
npm run build
```

Build output appears in:

```text
dist/
```

For Windows users, upload the installer and update files from `dist`.

## 4. Create GitHub Release

On GitHub:

1. Open the repository.
2. Go to `Releases`.
3. Click `Draft a new release`.
4. Create a tag such as `v1.0.1`.
5. Add release notes.
6. Upload the generated files from `dist/`.
7. Publish the release.

For auto-update, include these files:

```text
Local-Prompt-Studio-<version>-win-x64.exe
Local-Prompt-Studio-<version>-win-x64.exe.blockmap
Local-Prompt-Studio-<version>-win-x64.zip
latest.yml
```

## Automatic Updates

Local Prompt Studio includes automatic update support through `electron-updater`.

The app checks GitHub Releases for newer versions from:

```text
openerai/local-prompt-studio
```

When a user opens the installed app, it checks for a newer release. Users can also click `업데이트 확인` inside the app.

Important:

- Auto-update works only in the installed packaged app.
- Auto-update does not run during `npm start` development mode.
- The GitHub Release must include the installer/update files generated by electron-builder.
- The version in `package.json` must be higher than the user's installed version.
- If you want users to receive an update, publish a new GitHub Release with a higher version.

## Manual Updates

If auto-update fails, users can still download the latest installer from GitHub Releases.

## Release Checklist

Before publishing:

1. Increase `package.json` version.
2. Run `npm run test:syntax`.
3. Run `npm run build`.
4. Create a GitHub Release tag such as `v1.0.1`.
5. Upload files from `dist/`.
6. Publish the release.

After release, installed apps can detect the new version.
